# Lumi Bank demo

Prototype giao diện dashboard ngân hàng hư cấu, được xây dựng bằng HTML, CSS và JavaScript thuần.

## Chạy thử

Mở `index.html` trực tiếp trong trình duyệt hoặc chạy một static server trong thư mục này:

```powershell
python -m http.server 8000
```

Sau đó truy cập `http://localhost:8000`.

## Phạm vi an toàn

- Lumi Bank là thương hiệu hư cấu, không liên quan đến bất kỳ ngân hàng nào.
- Toàn bộ số dư và giao dịch đều là dữ liệu mẫu.
- Không có form đăng nhập, thông tin thẻ, OTP hay kết nối thanh toán thật.
